Записать расход, дело или потраченное время, пока ещё помнишь детали. COS собирает личный учёт в Telegram: короткие диалоги сохраняют данные в SQLite, а выгрузка в CSV позволяет разобрать их позже.

В очереди «СЕЙЧАС» можно держать максимум пять задач. Эта граница задаёт простой формат ежедневного использования: выбрать ближайшие дела и фиксировать происходящее по ходу дня.

## Что можно зафиксировать

- Расход с категорией, суммой и комментарием: обязательное, проекты, еда, инфраструктура или импульсная покупка.
- Время и энергию с типом активности и намерением.
- Задачу со статусом, типом и устройством либо свободную текстовую заметку.
- Расходы, время и задачи можно выгрузить за день, неделю или месяц. Напоминания возвращают к учёту после паузы.

Это проект для личного использования. Он показывает короткие пользовательские сценарии, хранение записей и регулярные фоновые задачи в Telegram-боте.

Обсудить похожий проект: [sh3l.beer](https://sh3l.beer).

## Установка

### Требования

- Python 3.10+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

### Шаги установки

1. Клонируй репозиторий или скачай файлы проекта

2. Установи зависимости:
```bash
pip install -r requirements.txt
```

3. Создай файл `.env` в корне проекта:
```bash
BOT_TOKEN=your_telegram_bot_token_here
DATABASE_PATH=cos.db
```

4. Запусти бота:
```bash
python -m bot.main
```

## Использование

После запуска бота отправь команду `/start` в Telegram. Появится клавиатура с основными действиями:

- **💸 Расход** - добавление расхода (категория → сумма → комментарий)
- **⏱ Лог времени** - фиксация активности (тип → намерение → энергия → комментарий)
- **🧠 Задача** - добавление задачи (тип → статус → название → устройство)
- **📝 Заметка** - быстрая запись текста
- **📊 Экспорт** - выгрузка данных в CSV за выбранный период

## База данных

Используется SQLite. Файл БД создаётся автоматически при первом запуске.

**Таблицы:**
- `expenses` - расходы
- `time_logs` - логи времени и энергии
- `tasks` - задачи
- `notes` - заметки

## Экспорт данных

Экспорт доступен в формате CSV для трёх типов данных:
- Расходы
- Логи времени
- Задачи

Периоды экспорта: День, Неделя, Месяц.

## Система напоминаний

При старте планировщик выбирает интервал из `REMINDER_INTERVALS`. На каждом срабатывании бот проверяет записи за последние 6 часов и отправляет напоминание, если новых данных нет. Частота сообщений зависит от интервала и активности пользователя.

## Принципы работы

Короткие диалоги рассчитаны на запись в моменте. В учёт попадают только сохранённые данные, все они лежат в одной базе. Подробный анализ вынесен за пределы бота: для него предусмотрен экспорт.

## Разработка

Проект использует:
- **aiogram 3.x** - Telegram Bot Framework
- **SQLAlchemy** - ORM для работы с БД
- **APScheduler** - планировщик для reminders
