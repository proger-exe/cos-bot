Telegram-бот для полного выноса операционки (финансы, время, задачи, заметки) из головы пользователя.

## Описание

COS помогает снизить когнитивную нагрузку, позволяя быстро фиксировать реальность в моменте. Все данные сохраняются в базу и могут быть экспортированы для анализа вне Telegram.

## Возможности

- 💸 **Учёт расходов** по категориям (Обязательное, Проекты, Еда, Инфра, Импульс)
- ⏱ **Логирование времени и энергии** с типами активности и намерениями
- 🧠 **Управление задачами** с ограничением очереди "СЕЙЧАС" (макс. 5 задач)
- 📝 **Быстрые заметки** для сброса когнитивного давления
- 📊 **Экспорт данных** в CSV (День, Неделя, Месяц)
- 🔔 **Система напоминаний** о необходимости фиксации данных

## Установка

### Требования

- Python 3.10+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

### Шаги установки

1. Клонируй репозиторий или скачай файлы проекта

2. Установи зависимости:
```bash
pip install -r requirements.txt
```

3. Создай файл `.env` в корне проекта:
```bash
BOT_TOKEN=your_telegram_bot_token_here
DATABASE_PATH=cos.db
```

4. Запусти бота:
```bash
python -m bot.main
```

## Использование

После запуска бота отправь команду `/start` в Telegram. Появится клавиатура с основными действиями:

- **💸 Расход** - добавление расхода (категория → сумма → комментарий)
- **⏱ Лог времени** - фиксация активности (тип → намерение → энергия → комментарий)
- **🧠 Задача** - добавление задачи (тип → статус → название → устройство)
- **📝 Заметка** - быстрая запись текста
- **📊 Экспорт** - выгрузка данных в CSV за выбранный период

## База данных

Используется SQLite. Файл БД создаётся автоматически при первом запуске.

**Таблицы:**
- `expenses` - расходы
- `time_logs` - логи времени и энергии
- `tasks` - задачи
- `notes` - заметки

## Экспорт данных

Экспорт доступен в формате CSV для трёх типов данных:
- Расходы
- Логи времени
- Задачи

Периоды экспорта: День, Неделя, Месяц.

## Система напоминаний

Бот автоматически отправляет 3-5 напоминаний в день, если пользователь не фиксировал данные в течение 6 часов. Сообщения без вежливых форм, прямые и по делу.

## Принципы работы

1. **Минимальный ввод** - все диалоги оптимизированы для быстрого ввода (≤20 сек)
2. **Один источник правды** - все данные в одной БД
3. **Нет записи = не существует** - только зафиксированные данные учитываются
4. **Анализ отделён от сбора** - анализ данных происходит вне Telegram через экспорт

## Разработка

Проект использует:
- **aiogram 3.x** - Telegram Bot Framework
- **SQLAlchemy** - ORM для работы с БД
- **APScheduler** - планировщик для reminders

## Лицензия

Проект для личного использования.
